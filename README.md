
# SpendWise – Student Expense and Budget Planner

SpendWise is a frontend-based expense tracking and budget planning web application designed to help students record transactions, monitor spending, and manage monthly budgets.

## Features

- Add, edit, and delete income and expense transactions
- View total income, total expenses, and current balance
- Track weekly and monthly expenses
- Visualize current-month expenses by category using a doughnut chart
- Set monthly and category-wise budgets
- Receive warnings when budget limits are approaching or exceeded
- Store transactions and budgets in browser LocalStorage
- Export transaction history to CSV for use in spreadsheet applications
- Responsive layout for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser LocalStorage
- JavaScript Blob API for CSV export

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Add transactions and explore the budgeting features.

An internet connection may be required to load Chart.js if the project uses its CDN.

## Data Storage

SpendWise uses browser LocalStorage to save transactions and budget settings. Data remains in the same browser's storage and is not synchronized across devices.
